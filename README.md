1. Почему папку venv не нужно коммитить в Git?
Она занимает много места, содержит тысячи системных файлов и привязана к конкретной операционной системе и путям на компьютере автора — на другом ПК она всё равно не заработает.
2. Что произойдёт, если склонировать репозиторий без venv, и как восстановить окружение?
Проект не запустится из-за отсутствия библиотек (ошибка ModuleNotFoundError). Чтобы восстановить окружение, разработчику нужно создать своё пустое окружение (python -m venv venv), активировать его и установить все пакеты из списка: pip install -r requirements.txt.
3. Зачем нужен requirements.txt и как он связан с .gitignore?
Файл requirements.txt хранит список всех библиотек проекта и их точных версий для быстрого развёртывания на другом устройстве. В отличие от папки venv (которую добавляют в .gitignore), файл requirements.txt не игнорируется и обязательно попадает в Git.
